2026-08-20 — Authentication System, Vercel Deployment Configuration & Full Release

What changed:
- Implemented complete Authentication & Session management:
  * Added hashed password field to User model in Prisma schema.
  * Created auth library (src/lib/auth.ts) with bcrypt password hashing and jose JWT session tokens.
  * Added Auth API routes: /api/auth/login, /api/auth/logout, and /api/auth/me with HTTP-Only secure cookies.
  * Added Next.js Edge Middleware (src/middleware.ts) protecting all dashboard, entries, commands, and admin routes.
  * Created dark technical login page (/login) with developer access banner and credentials form.
  * Added user session display, role badge, and logout action to Sidebar.
  * Provisioned default administrator in database seed (admin@knowledge.local / AdminPassword123!).
- Configured project for seamless Vercel deployment:
  * Added "postinstall": "prisma generate" in package.json.
  * Verified compatibility with remote Neon serverless PostgreSQL.
  * Updated .env.example with JWT_SECRET and deployment variables.
- Added automated unit test suite for authentication (tests/auth.test.ts).
- Initialized git repository with clean main branch ready for remote push.

Why:
- To secure the knowledge base with frictionless session-based authentication without public registration, and make the application directly deployable to Vercel in 1 click.
